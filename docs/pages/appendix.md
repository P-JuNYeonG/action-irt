# Supplementary Materials

This page summarizes additional materials that accompany the manuscript and repository.

## Implementation Details

| Component | Main settings |
|-----------|---------------|
| Hybrid Word2Vec | 20-dimensional embeddings, context window 5, 5 negative samples |
| Temporal augmentation | Elapsed time, squared elapsed time, and inter-action interval |
| LSTM autoencoder | Latent dimension \(D = 1\) in the empirical analysis |
| Action-IRT MCMC | 50,000 iterations, 10,000 burn-in, thinning interval 10 |
| Variable selection | Spike variance \(\tau^2 = 0.001\), slab variance \(\nu^2 = 2.5\) |

## Preprocessing Prompt Materials

The LLM-assisted preprocessing step standardizes noisy event descriptions into concise action-label components. This step is limited to string-level normalization and is followed by researcher review. Prompt materials are intended to be stored under:

`supplementary/llm_prompts/`

## Full Item Tables

The main manuscript discusses three representative items. Complete important-action tables for all 14 PSTRE items are intended to be stored under:

`supplementary/full_item_tables/`

## Diagnostics And Figures

MCMC diagnostics and analysis figures are intended to be generated by scripts in `analysis/` and stored in `analysis/figures/`. The repository does not redistribute raw PIAAC log data.

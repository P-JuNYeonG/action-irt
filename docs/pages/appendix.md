## B. LLM-Assisted Preprocessing

- **Model:** Claude Sonnet 4.5 (Anthropic, 2025) via OpenRouter API
- **Purpose:** Standardize noisy event descriptions into concise, consistent action labels
- **Constraints:** Event types processed independently; character-number combinations preserved; human review of all outputs

Full prompt text is provided in the repository under `supplementary/llm_prompts/`.

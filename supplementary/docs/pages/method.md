# Method

The proposed framework converts raw process-data sequences into action-level effect estimates that can be interpreted within an item response modeling framework. The model is designed to avoid manually specifying process indicators while retaining action-level interpretability.

## Action Unit Construction

Raw log records are transformed into standardized action units. Each unit combines a broad event category, such as `MAIL_DROP` or `FOLDER_VIEWED`, with cleaned contextual information from the event description when that information is substantively meaningful. The resulting unit labels preserve both the type of interface operation and the task-specific object involved.

The preprocessing pipeline has three parts:

1. Rule-based cleaning for restart handling, duplicate removal, and consolidation of multiple records generated by a single user action.
2. LLM-assisted standardization of noisy event descriptions, restricted to conservative string-level normalization.
3. Construction of final action-unit sequences with timestamps for each respondent-item pair.

## Stage 1: Hybrid Word2Vec

Each action unit is embedded using a skip-gram objective adapted to process-data sequences. The model also uses token-level structure in action labels, following the intuition of FastText-style subword composition.

$$
\mathbf{e}(u) = \mathbf{v}_u + \sum_{r=1}^{m} \mathbf{v}_{g_r}.
$$

The embedding for each observed action is augmented with elapsed time, squared elapsed time, and the interval since the previous action.

## Stage 2: LSTM Autoencoder

The time-augmented embedding sequence is compressed using an LSTM autoencoder. The encoder processes the action sequence in order, and a bottleneck projection produces a low-dimensional latent representation for each action occurrence:

$$
\mathbf{C}_{ijn} =
\mathbf{W}_{\mathrm{proj}}\mathbf{h}_{ijn} +
\mathbf{b}_{\mathrm{proj}} \in \mathbb{R}^{D}.
$$

This representation is intended to capture both the action identity and the sequential context in which the action occurred.

## Stage 3: Action-IRT

The latent action representations are entered into an extended Rasch model:

$$
\mathrm{logit}(\pi_{ij})
= \alpha_i + \beta_j
+ \sum_{l=1}^{N_{.j.}}
\left(
\sum_{d=1}^{D} \omega_{jl}^{(d)}\bar{C}_{ijl}^{(d)}
\right) I(l \in A_{ij}).
$$

The action weights are assigned spike-and-slab priors:

$$
\omega_{jl}^{(d)} \mid \lambda_{jl}^{(d)}
\sim
\begin{cases}
N(0,\tau^2), & \lambda_{jl}^{(d)} = 0, \\
N(0,\nu^2), & \lambda_{jl}^{(d)} = 1.
\end{cases}
$$

Posterior inclusion probabilities summarize evidence that an action weight belongs to the slab component.

## Important Action Criterion

For interpretation, the analysis uses a group-contrast statistic:

$$
\Delta E_{jl}^{(t)}
= E_{jl}^{\mathcal{C}(t)} - E_{jl}^{\mathcal{I}(t)}.
$$

An action is classified as important when the 95% highest posterior density interval of \(\Delta E_{jl}\) excludes zero. The sign and magnitude of \(\Delta E_{jl}\) are interpreted as ability-adjusted partial effects rather than marginal effects of performing the action.
